The dojo fee reminder (owner / partner dashboard → "Send reminder", `feeReminder` in `lib/guardian.ts`) adds
two lines when the gym has a UPI ID:

    Pay via UPI: *demodojo@okicici*
    Please add "Aarav Reddy" in the payment note.

New column `companies.upi_id`, empty by default (so nothing changes for any gym until it's filled), set by
super admin in Companies → Edit → **UPI ID**. Adds one column and one check; nothing is dropped or deleted.
Owners can't change it: trigger `protect_company_columns` only lets them change `logo_url` / `banner_url`.
Staff of the gym read it with the rest of their company row (existing rule); logged-out visitors can't
(no `anon` grant).

## Step 1

Safe to run twice (the check is only added if it isn't there yet).

```sql
alter table public.companies add column if not exists upi_id text;

-- Same shape as the app's check (lib/guardian.ts upiProblem): name@bank, no spaces
do $$
begin
  if not exists (select 1 from pg_constraint where conname = 'companies_upi_id_format') then
    alter table public.companies add constraint companies_upi_id_format
      check (upi_id is null or upi_id ~ '^[A-Za-z0-9._-]{2,256}@[A-Za-z0-9]{2,64}$');
  end if;
end $$;

-- Check: expect every company, upi_id empty
select name, slug, upi_id from public.companies order by created_at;
```

The app works before and after this runs: until the column exists the UPI ID field is greyed out and the
reminder has no UPI lines.
