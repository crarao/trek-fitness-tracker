# 25 Oct 2026 — `plan_json` on weekly_plans (#14 structured plans)

Adds one empty, optional column for plans stored as days and exercises.
Existing plans are untouched (they get NULL and keep showing as text). No policy changes: the
existing weekly_plans rules (staff of the client's gym; clients read their own) cover the new column.

```sql
alter table public.weekly_plans add column if not exists plan_json jsonb;
```

Check:

```sql
select column_name, data_type from information_schema.columns
where table_schema = 'public' and table_name = 'weekly_plans' and column_name = 'plan_json';
```

Shape (written by the app, see `lib/plan-structure.ts`):
`{ "version": 1, "days": [ { "day": "Mon", "rest": false, "focus": "Lower Body Strength",
"exercises": [ { "name": "Goblet Squat", "sets": "3", "reps": "10", "rest": "60 s", "note": "" } ] }, … 7 days ], "note": "…" }`

`plan_details` keeps a text copy of every structured plan, so anything reading text keeps working.
Without the column the app still saves plans (text only).
